Native V4 object/environment customData ingestion is **unverified** for this installed profile. CM's V4 editor and Info support remain intact. Native configuration, saved environment selection, handedness and recording cameras are user context, not additional map request keys. Noodle-only movement, dissolve, gravity and look semantics have separate coverage. Chroma basic events/custom-event discriminators and material/shader/geometry families have separate request audits.


The color observer checks every authored chain body and every renderer in its current model. Surplus inactive pooled nodes belong to earlier source chains and are excluded by the authoritative SliceCount−1, rather than by visibility filtering. Native missing-point fallback and before/null/after color assertions remain unchanged. The ordering diagnostic `20261011-221757` confirmed two authored colored bodies plus one inactive surplus white body; this was a test ownership artifact, not a production color defect.

Malformed-reference coverage is precise for named points and Regex syntax. It does not establish exhaustive parity for every invalid JSON type or invalid instruction. Shared Heck/Noodle transforms are exercised by the relevant motion/edit fixtures; this inventory describes Chroma request parsing and routing rather than claiming exhaustive trajectory parity across arbitrary Noodle programs.

Final validation: the complete run `20261011-224129` passed 1,629 cases and exposed three obsolete test observers.
