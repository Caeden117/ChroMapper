# RingRotationTest_90fps_Short

120 BPM dense-propagation regression map. This first short capture separates a dense callback
pair and settles at `-900` degrees. It is intentionally retained alongside the later
`RingRotationTest_90fps_Short_RenderTrace` session, which groups that pair and settles at
`-810` degrees. Neither capture is a replacement for the other: fixed recurrence must be
validated against each capture's own wave-assignment sequence.
