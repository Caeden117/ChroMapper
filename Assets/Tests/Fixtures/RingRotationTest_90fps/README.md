# RingRotationTest_90fps

This fixture is a clone of the ring-rotation test map captured in Beat Saber 1.44.1 with the display refresh rate set to 90 Hz.

It uses the same map files as the 120 Hz and 170 Hz fixtures with distinct ChromaGLS captures:

- `ChromaGLS-RingWaveStarts.csv`
- `ChromaGLS-RingHalfBeatStates.csv`

Do not merge these captures with the other refresh-rate fixtures. Callback timing and sampled ring state are refresh-rate dependent.
