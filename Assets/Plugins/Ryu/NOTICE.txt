Imported portions: f2s.cs, f2s_full_table.cs, floating_decimal_32.cs and the
power-of-five/logarithm helpers from common.cs. The binary32 arithmetic and
lookup values are retained from the pinned C# port.

Local adaptations:
- Limit the import to binary32 formatting, with an internal Ryu.RyuSingle API.
- Replace C# 11 global aliases and file-scoped namespaces with Unity-compatible
  C# syntax, and expand control-flow bodies to match project formatting.
- Replace Unsafe-based character output with stack-allocated spans and
  BitConverter.SingleToInt32Bits, avoiding an additional package dependency.
- Write into a caller-owned span and return its length so the JSON writer can
  append directly to StringBuilder without allocating a string per number.
- Render the shortest decimal significand in fixed or scientific notation,
  using invariant JSON-compatible punctuation and an uppercase signed exponent.
- Preserve the project's existing zero and non-finite text conventions.
- Use conditional System.Diagnostics assertions and omit the C compiler branch.
